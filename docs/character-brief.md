## 0. 먼저 — 마블은 닮게 만들지 않는다

캡틴아메리카와 닥터스트레인지는 디즈니의 상표이자 저작물이다.
형상을 닮게 만들면 **스토어 게시 중단 + 상표 등록 거절**이 실제로 온다.
그림 생성 모델에 브랜드 이름을 넣는 것도 하지 않는다.

**가져오는 것은 형식이고, 버리는 것은 형상이다.**

| 가져온다 | 버린다 |
|---|---|
| 정면 대칭, 단단한 실루엣 | 별 문양, 흰·빨강·파랑 동심원 방패 |
| 원형 방패를 든 자세 | 날개 헬멧, 이마의 A |
| 색 3개로 절제 | 망토, 염소수염, 반지 |
| 시간을 다루는 도구 | 주황 마법진·룬 문자 |

## 1. 결정적 차이 — 시계가 얼굴이 아니라 손에 있다

지금 마스코트(`promo-bg.png`)가 버려진 이유는 **시계가 얼굴이었기 때문**이다.
얼굴이 시계면 그 캐릭터는 "알람"이 전부가 되고, 스토어에 깔린 수백 개 알람 앱과 같아진다.

이번 안에서 시계는 **손에 들린 방패**다. 얼굴이 아니라 도구다.
도구는 캐릭터의 정체가 아니라 **능력**을 말한다. 완전히 다른 물건이다.

## 2. 앱 안에 이미 있는 재료

### "오구"는 숫자가 아니라 소리다

`src/data/oguData.js`

```
오구: A5(880Hz) 0.13초  →  E5(659Hz) 0.46초
      짧고 높게 "오"        길고 낮게 "구"
```

사용자가 매시간 몸으로 겪는 건 이 두 음이다. 앱 안에서 "59"를 글자로 보는 화면은 없다.
→ 방패가 울릴 때 **두 겹의 파동**이 퍼진다. 짧고 작은 것 하나, 길고 큰 것 하나.

### 캐릭터가 입을 상태가 이미 있다

| 체계 | 값 | 캐릭터에서 |
|---|---|---|
| 알람 상태 (`alarmContext.js`) | `focus` · `normal` · `binge` | 방패의 자세 |
| 활동 4축 (`appCategories.js`) | 🌱성장 `#4B6BD4` · 💬소통 `#2F7D62` · 🌿힐링 `#FF6B2C` · 🧭생활 `#B0B0B6` | 방패 테두리 색 |
| 사운드 톤 | 오구 · 여유 · 바쁨 · 유쾌 | 울림의 세기 |
| 오늘의 체크 | 미션 · 완주 · 할일 · 알람 | 방패에 켜지는 눈금 |

### 성격 — 코드에 이미 쓰여 있다

| 코드의 규칙 | 성격 |
|---|---|
| 힐링은 나쁜 시간이 아니다. 꾸짖지 말 것 | 평가하지 않는다 |
| 잰 것만 점수로 쓴다 | 지어내지 않는다 |
| 비교는 어제의 나뿐 | 남과 견주지 않는다 |
| 1분 개입. 집중 중엔 들이밀지 않는다 | 눈치가 있다 |
| AI를 품지 않는다. 다리만 놓는다 | 대신 해주지 않는다 |

한 줄로: **내 시간 앞에 서서 막아주고, 한 가지만 짚어주고 물러난다.**

방패가 맞는 이유가 여기다. 오구는 **공격하지 않는다.** 코치처럼 몰아붙이지 않고,
감시자처럼 보지 않는다. 앞에 서서 막아줄 뿐이다.

## 3. 5와 9 — 앱에 실재하는 것으로 채운다

지어낸 설정은 금방 들통난다. **5와 9는 앱이 실제로 하는 일에서 가져온다.**

### 🛡️ 방패가 막는 5가지

오구 지수가 v1.11.0에서 **5 : 9** 구조였다. 그 5를 되살린다.

| | 막는 것 | 앱의 무엇이 막나 |
|---|---|---|
| 1 | **순삭** — 모르는 사이 사라지는 시간 | 매시 59분 알람 · `mood: binge` 경고 |
| 2 | **미룸** — 시작을 안 함 | "지금 하나만" · 5분 미션 |
| 3 | **잊음** — 약속과 마감 | 달력 연동 · D-day |
| 4 | **막막함** — 뭘 할지 몰라 아무것도 안 함 | 오늘의 추천 미션 3개 · AI 질문 카드 |
| 5 | **자책** — 남과 비교하고 스스로를 깎음 | 비교는 어제의 나뿐 · 힐링을 꾸짖지 않음 |

**5번이 이 앱의 진짜 차별점이다.** 다른 시간관리 앱은 자책을 만들어낸다.
오구는 그것까지 막는다. 방패에 다섯 번째 겹이 있는 이유다.

### ⚡ 오구의 9가지 능력

앱이 실제로 가진 기능 아홉이다. 하나도 지어내지 않았다.

| | 능력 | 실체 |
|---|---|---|
| 1 | **정각 1분 전** | 매시 59분 알람 (`useAlarm`) |
| 2 | **안 적어도 안다** | UsageStats 자동 기록, 30분 슬롯 |
| 3 | **무엇이었는지 안다** | 앱 187개 분류표 → 성장·소통·힐링·생활 |
| 4 | **하루를 점수로** | 오구 지수 (성장 40 + 균형 20 + 실행 40) |
| 5 | **5분이면 되는 일** | 오늘의 추천 미션 60개, 몸·정리·머리에서 하나씩 |
| 6 | **지금 하나만** | 마감·우선순위로 고른 할일 1개 |
| 7 | **약속을 기억한다** | 기기 캘린더 연동 (읽기 전용) |
| 8 | **AI에게 건넨다** | 오구 브리지 — 질문 카드 15장, 돌아올 다리 |
| 9 | **어제의 나와 비교** | 리포트 · 7일 추세 · 월간 달력 |

**5는 지키는 힘, 9는 쓰는 힘.** 합쳐서 "매시 59분, 오구".

## 4. 형상

### 실루엣

```
머리   둥근 헬멧형. 눈 두 점만. 입 없음
몸     작고 단단한 상반신. 2.5등신
팔     둘. 왼팔에 방패
방패   정원(正圓). 몸통보다 크지 않게
```

**입을 그리지 않는다.** 웃는 입은 알림 장난감으로 읽힌다(v1에서 버린 이유).
눈 두 점만으로 상태를 말한다.

### 방패

```
테두리   60개 눈금. 59번째 하나만 주황으로 길고 진하게
안쪽     비어 있다. 문자판도 바늘도 넣지 않는다
          ─ 바늘을 넣는 순간 다시 "시계"가 된다
울릴 때  두 겹의 파동 (짧고 작은 것 → 길고 큰 것) = "오-구"
```

**59번째 눈금 하나가 이 캐릭터의 전부다.** 60개 중 하나만 다르다는 것이
"정각 1분 전"을 설명 없이 말한다.

### 상태 — 방패의 자세로

| 상태 | 방패 | 테두리 색 | 언제 |
|---|---|---|---|
| 기본 | 옆으로 내림 | 주황 `#FF6B2C` | 평소 |
| 알람 | 정면으로 들고 두 겹 파동 | 주황 | 매시 59분 |
| 집중 | 내린 채 가만히 | 파랑 `#4B6BD4` | `mood: focus` — **방해하지 않는다** |
| 순삭 | 정면으로 들고 버팀 | 주황(진하게) | `mood: binge` |
| 쉼 | 바닥에 세워 기댐 | 주황(연하게) | 힐링 기록 중 |
| 완주 | 들어 올림, 눈금 4칸 점등 | 초록 `#1E7A58` | 체크 4/4 |

**집중 중에는 방패를 들지 않는다.** 알람의 최대 불만이 "집중을 깬다"였다.
캐릭터도 그 규칙을 지켜야 한다.

### 색

주색은 `theme.accent.primary` `#FF6B2C` 하나 + 차콜 `#111111` + 흰색.
상태색은 활동 4축 값을 **그대로** 쓴다. 캐릭터용 색을 새로 만들지 않는다 —
만드는 순간 앱 색과 어긋나고, 어긋나면 둘 다 틀린 것이 된다.

## 5. 아이콘은 방패만 쓴다 ★

**전신 캐릭터는 16px에서 죽는다.** 팔·눈·방패가 뭉개져 주황 덩어리만 남는다.
런처 아이콘(48dp)·알림 아이콘(24dp)에서는 아무것도 안 보인다.

그래서 둘로 나눈다.

| | 쓰는 것 | 쓰는 곳 |
|---|---|---|
| **심볼** | 방패만 (60눈금 + 59번째 하나) | 런처 · PWA · 파비콘 · 알림 |
| **캐릭터** | 전신 오구 | 스토어 그래픽 · 온보딩 · 알람 팝업 · 인스타 |

방패는 단순한 원반이라 16px에서 산다. 테두리 눈금이 뭉개져도 **59번째 주황 눈금은 남는다.**
원형이라 어떤 런처 마스크(원·둥근네모·스퀴클)에도 잘린 곳이 안 생긴다.

이것이 **아이콘 셋이 갈린 문제의 답**이기도 하다 — 정본 방패 SVG 하나에서 전부 뽑는다.

## 6. 하지 않는 것

- 마블 캐릭터를 닮게 만들지 않는다 (0장)
- 방패 안에 바늘·문자판을 넣지 않는다 — 넣는 순간 시계가 된다
- 입을 그리지 않는다
- 새싹을 쓰지 않는다 — 🌱은 성장 축의 기호다. 캐릭터가 쓰면 4축 중 하나로 편든다
- 보라·분홍을 쓰지 않는다 (현 PWA 아이콘 색, 앱 어디에도 없다)
- 무기를 들리지 않는다 — 오구는 막기만 한다
- 전신을 런처 아이콘으로 쓰지 않는다

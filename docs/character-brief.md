## 2. 왜 다시 시계 몸인가

v2 에서 "시계가 얼굴이면 수백 개 알람 앱과 같아진다"고 버렸다. 이번에는 다르다.
**정체가 시계가 아니라 새싹이다.** 시계는 씨앗(출발점)이고, 자라는 것이 이 캐릭터다.
알람 앱 중에 자라는 캐릭터는 없다.

---

## 3. 성장 — 무엇이 오구를 키우나 ★

이 장이 앱 규칙과 가장 많이 부딪힌다. `CLAUDE.md` 의 오구 지수 규칙을 그대로 따른다.

| 키우는 것 | **오늘의 체크 4/4 를 채운 날의 누적 수** |
|---|---|
| 이유 | 체크는 이진 항목이라 게임화해도 정직하다 (`CHECKS`) |

**쓰지 않는 것과 이유:**

| 쓰지 않는다 | 이유 (`CLAUDE.md`) |
|---|---|
| 성장 시간(분) | **성장 40(잰 시간)은 게임 화폐로 만들지 않는다** |
| 앱 연 횟수·사용 시간 | 앱을 많이 열어서 오르는 점수는 만들지 않는다 |
| 연속 일수만으로 | 끊기는 순간 자책이 된다 — 오구가 막는 다섯 번째가 자책이다 |
| 남과 비교·순위 | 비교는 어제의 나뿐 |

**오구는 시들지 않는다. 퇴화하지 않는다.**
폰을 안 쓴 날, 체크를 못 채운 날은 감점이 아니다 — 산책·수면·대면 대화는 측정되지 않을 뿐
좋은 시간이다. 며칠 못 와도 오구는 그 자리에서 기다린다.

### 단계 (안)

| 단계 | 모습 | 누적 (안) |
|---|---|---|
| 1 | 새싹 — **지금 원본** | 시작 |
| 2 | 떡잎이 커지고 잎이 하나 더 | 7일 |
| 3 | 줄기가 서고 잎이 무성 | 21일 |
| 4 | 꽃봉오리 | 45일 |
| 5 | 주황 꽃이 핀다 | 90일 |

단계마다 바뀌는 것은 **머리 위 식물뿐**이다. 몸·얼굴·비례는 그대로 둔다 —
바뀌면 다른 캐릭터가 되고, 아이콘도 같이 흔들린다.

## 4. 마법의 시간방패

자라면서 얻는 물건이다. 언제 얻는지는 아직 정하지 않았다 (7장).

2026-10-28 시안 작업에서 확정된 것만 옮긴다 (시안: `.tmp-char/cute/`):

```
모양     원형. 도톰한 크림색 테에 둥근 돌기 12개 (시계 눈금)
면       주황. 가운데 굵고 둥근 흰 59
신비     59번째 분 자리(12시 바로 왼쪽)에 호박색 보석 하나
울릴 때  59가 안에서부터 등불처럼 켜진다 — 평소엔 은은하게
```

- **방패는 막기만 한다.** 공격하지 않는다. 무기를 들리지 않는다.
- **주황 마법진·룬 문자를 쓰지 않는다.** 그쪽으로 가면 닥터스트레인지가 된다.
- 금속·리벳·가시·거너메탈을 쓰지 않는다 — 무겁고 차가워서 버린 길이다.
- 날개는 방패에 달지 보류. 이미지로는 날개 모양이 매번 달라져 고르지 못했다.

## 5. 5가지와 9가지

v2 의 목록을 유지한다. 둘 다 앱이 실제로 하는 일에서 뽑았다.

**막는 5가지** — 순삭 · 미룸 · 잊음 · 막막함 · 자책

**9가지 능력** — 정각 1분 전 · 안 적어도 안다 · 무엇이었는지 안다 · 하루를 점수로 ·
5분이면 되는 일 · 지금 하나만 · 약속을 기억한다 · AI에게 건넨다 · 어제의 나와 비교

(능력 9가지를 단계마다 하나씩 "깨어나는" 것으로 보여줄지는 7장에서 정한다.)

## 6. 성격 — 코드에 이미 쓰여 있다

| 코드의 규칙 | 오구 |
|---|---|
| 힐링은 나쁜 시간이 아니다 | 꾸짖지 않는다 |
| 잰 것만 점수로 쓴다 | 지어내지 않는다 |
| 비교는 어제의 나뿐 | 남과 견주지 않는다 |
| 1분 개입, 집중 중엔 들이밀지 않는다 | 눈치가 있다 |
| AI를 품지 않는다 | 대신 해주지 않는다 |

**집중(`focus`) 중에는 오구가 나서지 않는다.** 알람의 최대 불만이 "집중을 깬다"였다.

## 7. 정해야 할 것

1. **새싹과 🌱 성장 축.** 앱에서 🌱은 성장 분류의 기호다. 캐릭터 머리의 새싹이 성장 축의
   편을 드는 것으로 읽히지 않게 할지, 아예 같은 뜻(나의 성장)으로 받아들일지
2. **색.** 원본 주황 `#F27F45` 은 앱 주황 `#FF6B2C` 보다 부드럽다.
   그림은 원본 색, 앱 UI 는 앱 색으로 둘지, 하나로 맞출지
3. 성장 단계 수와 누적 일수
4. 시간방패를 얻는 시점 (특정 단계 / 9가지 능력을 다 깨운 뒤 / 처음부터)
5. "5가지 ??" 의 ?? — 막는 5가지로 둘지, 성장 5단계로 둘지
6. 런처 아이콘을 캐릭터 얼굴로 할지 — 새싹이 원형 실루엣에 표시를 하나 남겨
   48dp 에서 다른 시계 아이콘과 구분된다. 실측 필요

## 8. 하지 않는 것

- 원본 그림을 이미지 모델로 다시 그리지 않는다 — 부품 합성만
- 시들기·퇴화·감점 연출을 만들지 않는다
- 성장 시간·앱 사용량으로 키우지 않는다
- 마블 캐릭터를 닮게 만들지 않는다 (별 문양, 흰·빨강·파랑 동심원, 날개 헬멧, 망토, 주황 마법진)
- 무겁게 만들지 않는다 — 금속·리벳·가시·어두운 색
- 보라·분홍을 쓰지 않는다 (현 PWA 아이콘 색)

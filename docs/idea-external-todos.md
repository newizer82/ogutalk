> 대표 전용 노션 연동을 만들었다가 취소했다. 변경분은 `.tmp-char/notion-shelved/` (git 밖).

## 대표 전용판에서 배운 것

실제 노션 할 일 7개를 384px 팝업에 넣어 보고 나온 결론.

- **하나만 보여준다.** 5줄을 넣자 팝업이 여섯 덩어리가 됐고, "지금 하나만" 과 할 일이 두 군데 생겼다
  ("제안은 언제나 하나" 원칙이 깨진다). 5개 중 3개는 제목이 잘렸다.
- **급한 것이 먼저다.** 마감순으로만 고르자 `우선=급함` 이 빠지고 `나중` 이 들어왔다.
- **외부 데이터를 폰에 저장하지 않는다.** `allowBackup="true"` 에 제외 규칙이 없어서
  localStorage 에 두면 구글 드라이브 백업으로 나간다. 메모리에만 둔다.
- **"다시 묻지 않음" 표시는 계정별로.** 기기 단위로 두면 다른 계정으로 한 번 로그인한 폰에서 영영 꺼진다.
- 비밀값을 쓰는 순간 공개 저장소가 걸린다 — `.gitignore` 가 `.env`·`supabase/functions/.env` 를 막지 않는다.

전체 사용자로 넓히면 하나가 더 생긴다: **사람마다 노션 DB 구조가 다르다.**

## 후보 넷

| | 방법 | 작업량 | 서버·토큰 | 대상 |
|---|---|---|---|---|
| ① | 59분에 내 할 일 앱을 **열어주기만** | 아주 작음 | 없음 | 모든 할 일 앱 |
| ② | 노션·메모에서 **공유 → 오구톡** 으로 가져오기 | 작음 | 없음 | 모두 |
| ③ | 기기 캘린더의 **오늘 마감**을 "지금 하나만" 후보로 | 작음 | 없음 | 캘린더에 마감을 적는 사람 |
| ④ | 노션 공개 연동(OAuth) + DB·칸 매핑 | 큼 | **필요** | 노션 사용자 |

### ① 열어주기
설정에서 할 일 앱(또는 노션 페이지 주소) 하나를 고르면 팝업에 "📋 내 할 일 열기" 버튼 하나.
데이터를 읽지 않는다. 오구 브리지와 같은 생각 — 오구톡은 품지 않고 다리만 놓는다.
약점: 팝업에 내용이 안 보인다.

### ② 공유로 가져오기
돌아올 다리(`takeShared()`)가 이미 있다. 사용자가 고른 것만 들어오니 동의 문제도 없다.
약점: 노션에서 완료해도 오구톡엔 남는다 (동기화 없음).

### ③ 캘린더
`READ_CALENDAR` 이미 있음. 새 권한·서버 없음. 일정 조회는 지금처럼 달이 바뀔 때 1회 규칙을 지킨다.

### ④ 노션 연동
사용자별 토큰을 서버에 보관해야 한다 → 암호화·유출 대응·처리방침·Play 데이터 보안 수정.
"서버 비용 0 · 기기 밖으로 안 나간다" 와 정면으로 부딪힌다. 칸 매핑 화면에서 초보가 이탈하기 쉽다.

측정은 버튼 탭 이벤트 하나만 — 사용 기록은 기기 밖으로 보내지 않는다.

## 어느 안이든 지킬 것

- 팝업에는 하나만. 집중(`focus`) 중에는 띄우지 않는다
- 완료 버튼을 팝업에 두지 않는다 (제거된 기능 — 점수를 벌려고 누르게 된다)
- 실패하면 조용히 숨긴다. 알람은 할 일이 없어도 알람이다
- 스토어 스크린샷에 실제 할 일 제목이 찍히지 않게 (`store/README.md`)

# 출시 노트 — 오구톡 1.21.0 (versionCode 54)

Play Console > 출시 > 내부 테스트(또는 프로덕션) > **이번 버전의 새로운 기능** 에 붙여넣습니다.
한국어 기준 500자 제한. 아래 A안이 기본, 길면 B안.

versionCode 51~53 누적 내용입니다 (51·52 는 내부 테스트만 올라갔고 사용자에게는
53 이 처음 보이는 1.21.0 이므로, 세 빌드의 변경을 한 장으로 묶었습니다).

## 쓰지 않은 표현과 이유

- **"AI 기능 탑재"** — 거짓이다. 오구톡은 AI를 품지 않고 사용자의 AI에 질문을 건넨다.
  과장하면 리뷰에서 "AI가 답을 안 해준다" 가 돌아온다.
- **"생산성 향상"** — 아무것도 말하지 않는 단어다. 무엇이 어떻게 달라지는지를 쓴다.
- **버전 번호·내부 용어**(compact, 오구 브리지, versionCode) — 사용자는 모른다.
- **"오늘 하루를 100점으로"** — 지수 설명은 이미 앱 안 배너가 한다. 출시 노트에서 또 설명하지 않는다.

## 프로덕션 승격용 — 1.17.0 에서 올라오는 사용자용

프로덕션이 1.17.0(42)이면 사용자는 1.18·1.19·1.20 을 건너뛰고 올라온다.
위 A~C 안은 51~53 만 다루므로 프로덕션에는 맞지 않는다. 아래를 쓴다.

```
🤖 알람에서 바로 AI에게 (신규)

매시 59분, "지금 물어볼 것" 을 한 장 꺼내 드려요.
누르면 폰에 깔린 AI 앱이 질문과 함께 열리고,
받은 답은 공유로 되돌리면 할일·메모로 담겨요.

• 오구 지수가 성장·힐링·소통 세 축으로 새로워졌어요
• 홈 맨 위에서 오늘 모은 점수가 차오릅니다
• 달력에서 약속·일정을 바로 추가하고 고칠 수 있어요
• 여러 날 일정은 띠로 이어집니다
• 폰에서 바꾼 설정이 PC 에서도 보여요
• 메모에 링크를 붙이면 제목이 보이고, 600자까지
• 시간대마다 "지금 내 숫자" 를 알려드려요
```

### 어느 버전에서 온 것인가

| | |
|---|---|
| 1.18.0 | 기기 간 설정·오구 지수 동기화, 웹 설치 안내 |
| 1.19.0 | 달력에서 약속·일정·계획 추가·수정·삭제, 할일 탭 달력 |
| 1.20.0 | 오구 지수 3축 재설계, 홈 히어로 3축, 시간대 배너, 시간대별 분류 수정 |
| 1.21.0 | 오구 브리지(AI), 돌아올 다리, 오늘의 체크, 메모 링크, 달력 띠 |

### 프로덕션 승격 전 확인

점수 공식이 1.20.0 에서 바뀌었다 — 1.17.0 사용자는 **점수가 달라진다**.
FORMULA 번호로 과거 점수와 비교하지 않게 막아 뒀지만, "어제보다" 가 한동안 안 보인다.
이건 의도된 동작이다 (다른 잣대로 잰 값을 비교하면 거짓말이 된다).

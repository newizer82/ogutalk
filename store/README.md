# 스토어 자산

Play Console > 스토어 설정 > 그래픽

| 자산 | 파일 | 규격 |
|---|---|---|
| 그래픽 이미지 | `feature-1024x500.png` | 1024×500, 필수 |
| 휴대전화 스크린샷 | `01-*.png` ~ `08-*.png` | 1080×1920, 2~8장 |

## 다시 찍는 법

1. 로그인/로그아웃을 고른다.
   - **로그아웃** — 안전하다. 내장 시드(기획서 작성 · 운동 30분)만 나온다.
     대신 서버에 있던 체크인이 빠져 점수가 떨어지고, AdMob 배너가 뜬다 → `--ad` 로 찍는다.
   - **로그인** — 점수와 기록이 살아 있다. 대신 화면마다 개인정보를 눈으로 확인해야 한다.
2. 폰 USB 연결 (`adb devices` 로 확인)
3. 화면을 옮겨가며 `adb shell screencap -p /sdcard/s.png` → `adb pull` 로 1080×2340 캡처
   (파일 이름은 `scripts/store-shots.mjs` 의 `SHOTS` 와 맞춘다)
4. `node scripts/store-shots.mjs <캡처폴더> store` (로그아웃 캡처면 끝에 `--ad`)
5. **합성한 8장을 전부 눈으로 본다** — 아래 "박히면 안 되는 것" 대로.

## 찍을 때 화면 맞추기

- **카드 경계에서 멈춘다.** 스크롤 중간에서 찍으면 맨 위가 카드 중간에 잘려
  고장난 화면처럼 보인다. 맨 위가 중요한 자리다 — 아래는 어차피 잘린다.
- 달력은 요일 머리글(일~토)까지 보이게. 반만 잘린 줄은 버그로 읽힌다.
- 배너는 돌아간다. 찍히는 배너가 그 화면 문구와 어긋나면 한 바퀴 기다린다.

## 박히면 안 되는 것 (로그인 상태로 찍을 때)

- **설정 > 볼 캘린더** — 구글 계정 주소와 삼성 계정 번호가 줄줄이 나온다.
  개인정보 문구를 보여주려면 *설정 > 자동 활동 기록* 쪽을 찍는다.
- 알람 팝업의 "지금 하나만" — 실제 할일 제목이 그대로 뜬다
- 메모·할일 목록, 약속 제목, 프로필 이메일

## 언제 찍을 것인가

**성장 시간이 쌓인 날 오후.** 점수 카드가 "성장 0분 · 힐링 15시간" 으로 나오면
"이 앱은 내가 하루를 버렸다고 알려준다" 로 읽힌다. 지어낼 수는 없으니 날을 고른다.

## 자동으로 잘려 나가는 것

- 상태바(통신사·배터리) — 내 폰 사정은 홍보물이 아니다
- 내비게이션 바
- **AdMob 배너** — 로그아웃 상태에서만 뜬다(`isPremium = isLoggedIn`).
  남의 상품 사진이 우리 스토어에 올라가면 안 된다

## 아이콘이 셋으로 갈려 있다

- `public/icon-512.png` — 보라·분홍 (PWA)
- 안드로이드 런처 아이콘 — 흰 시계판
- `public/promo-bg.png` 의 마스코트 — 주황 캐릭터 (그래픽 이미지에 쓴 것)

셋이 다르다. 정리가 필요하다.

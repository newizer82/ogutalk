# 스토어 자산

Play Console > 스토어 설정 > 그래픽

| 자산 | 파일 | 규격 |
|---|---|---|
| 그래픽 이미지 | `feature-1024x500.png` | 1024×500, 필수 |
| 휴대전화 스크린샷 | `01-*.png` ~ `08-*.png` | 1080×1920, 2~8장 |

## 다시 찍는 법

1. **폰에서 로그아웃** — 로그인 상태면 실제 약속·메모가 스크린샷에 박힌다.
   로그아웃하면 내장 시드(기획서 작성 · 운동 30분)로 바뀐다.
2. 폰 USB 연결 (`adb devices` 로 확인)
3. 화면을 옮겨가며 `adb exec-out screencap -p > sN-....png` 로 1080×2340 캡처
   (파일 이름은 `scripts/store-shots.mjs` 의 `SHOTS` 와 맞춘다)
4. `node scripts/store-shots.mjs <캡처폴더> store`
5. 다 찍었으면 **폰에서 다시 로그인**

## 언제 찍을 것인가

**성장 시간이 쌓인 날 오후.** 점수 카드가 "성장 0분 · 힐링 15시간" 으로 나오면
"이 앱은 내가 하루를 버렸다고 알려준다" 로 읽힌다. 지어낼 수는 없으니 날을 고른다.

## 자동으로 잘려 나가는 것

- 상태바(통신사·배터리) — 내 폰 사정은 홍보물이 아니다
- 내비게이션 바
- **AdMob 배너** — 로그아웃 상태에서만 뜬다(`isPremium = isLoggedIn`).
  남의 상품 사진이 우리 스토어에 올라가면 안 된다

## 아이콘이 셋으로 갈려 있다

- `public/icon-512.png` — 보라·분홍 (PWA)
- 안드로이드 런처 아이콘 — 흰 시계판
- `public/promo-bg.png` 의 마스코트 — 주황 캐릭터 (그래픽 이미지에 쓴 것)

셋이 다르다. 정리가 필요하다.

# 오구 방패 — 심볼 정본

```
ogu-shield.svg      정본. 모든 아이콘이 여기서 나온다
ogu-shield.png      1024 미리보기
```

생성: `python scripts/ogu_shield.py brand a`
(스크립트에 후보 a~d 가 남아 있다. a 가 확정본)

## 왜 이 모양인가

원형 방패에 동심원 넷, 중앙 작은 원에 **59**. 저쪽이 별이면 우리는 59다.

동심원 자체는 과녁·로델의 흔한 형식이라 문제가 없다. 피해야 하는 것은
**빨강-흰색-파랑 띠 + 별**이라는 특정 배색이고, 우리는 주황 계열 + 59다.
마블 형상은 닮게 만들지 않는다 — 상표이자 저작물이고, 스토어 게시 중단과
상표 등록 거절이 실제로 온다. 가져온 것은 형식(방패 + 문장)뿐이다.

**시계는 손에 들린 도구이지 얼굴이 아니다.** 앞선 마스코트(`public/promo-bg.png`)가
버려진 이유가 시계가 얼굴이었기 때문이다. 얼굴이 시계면 그 캐릭터는 "알람"이
전부가 되고, 스토어에 깔린 수백 개 알람 앱과 같아진다.

**방패는 공격하지 않는다.** 코치처럼 몰아붙이거나 감시자처럼 보지 않고 앞에 서서
막아줄 뿐이다 — `CLAUDE.md` 의 "꾸짖지 말 것 / 비교는 어제의 나뿐" 이 그 말이다.

## 버린 것과 이유

| 안 | 버린 이유 |
|---|---|
| 눈금 60개 두른 원반 | **그게 곧 시계 문자판이다.** 네 안이 전부 "주황 다이얼" 이라 구분도 안 됐다 |
| 눈금 링(면 없음) | 16px 에서 전부 소멸 |
| 59/60 호 | 1/60 = 6도. 작은 크기에서 안 보인다. 흰 호가 윤곽과 겹쳐 사라졌다 |
| 노치(돌기) | 32px 아래에서 흠집·자물쇠 고리로 보인다. 59 가 있으면 중복이다 |
| 방패형(아래 뾰족) | 원형으로 방향 변경 |
| 흰 띠 교차 | 띠가 넓어 **과녁**으로 읽힌다. 흰 띠가 흰 배경에서 구멍처럼 보인다 |
| 그라데이션 입체 | 앱 전체가 플랫인데 아이콘만 광택이 돌면 따로 논다. 32px 이하에서 뭉개져 효과도 없다 |
| 얇은 금속 테 | 32px 부터 선이 사라져 기본안과 구분 안 됨 |
| 중앙 짙게 + 흰 59 | 판독성은 가장 좋지만 중앙이 "구멍" 으로 보인다 |

**입체감은 그라데이션이 아니라 명암 4단으로 만든다.**
짙은 테 `#B8420F` → 주황 `#FF6B2C` → 밝은 주황 `#FFA470` → 흰 중앙.
그라데이션은 작아지면 뭉개지고 단계는 남는다. 플랫도 깨지 않는다.

## 확인한 것

- **런처 마스크 4종**(원·스퀴클·둥근네모·사각) 전부 잘리는 곳 없음
- 72/48/32/24dp 에서 실루엣 유지. **48dp 에서 59 판독** (중앙 원을 146 → 168 로 키워서 얻었다)
- 32px 아래에서 59 는 사라지지만 "겹 있는 주황 원" 으로 식별된다
- 흰 배경 · 어두운 배경 · 흑백 통과

## 아직 남은 것

1. **59 가 시스템 폰트(Segoe UI Black)다.** 정본은 패스로 떠야 한다 —
   지금 상태로는 다른 기계에서 다른 모양이 나온다
2. **알림 아이콘(24dp)** 은 안드로이드가 단색 실루엣으로 바꾼다 →
   59 없는 방패 실루엣만 따로 필요
3. **과녁으로 읽힐 여지가 남아 있다.** 중앙의 59 가 그걸 막는다 — 과녁에는 숫자가 없다.
   59 를 빼면 즉시 과녁이 되므로, 59 없는 변형을 만들지 않는다

## 하지 않는 것

- 방패 안에 시계바늘·문자판을 넣지 않는다 — 넣는 순간 시계가 된다
- 마블 캐릭터를 닮게 만들지 않는다 (별 문양·동심원 방패·날개 헬멧·망토·마법진)
- 보라·분홍을 쓰지 않는다 (현 PWA 아이콘 색. 앱 어디에도 없다)
- 전신 캐릭터를 런처 아이콘으로 쓰지 않는다 — 16px 에서 주황 덩어리만 남는다

색은 `src/styles/theme.js` 의 `accent.primary` `#FF6B2C`.
상태색이 필요하면 활동 4축 값을 그대로 쓴다. **캐릭터용 색을 새로 만들지 않는다.**
